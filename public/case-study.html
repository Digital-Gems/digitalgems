The challenge

The brokers receive quotes from several insurers, each in its own PDF layout. Putting them side by side meant manually copying premiums, excesses, extras and endorsements into a spreadsheet, line by line.

It was slow, easy to get wrong, and a poor use of experienced people. One missed excess value or a misread SASRIA line could change the advice a client received.

The solution

A simple web tool. A broker uploads the quote PDFs, and a few minutes later gets a formatted Excel comparison, ready to send to the client.

What makes it work

Insurance-aware extraction

Built-in rules for SASRIA, motor vehicles, excess values, surge cover cross-referencing, roadside assistance and car hire premium normalisation.

Spreadsheets that work

Live SUMIF formulas and correct numeric types, so totals update and nothing is stored as text. Clean, professional styling.

Under the hood

A modern web application platform front end for the brokers, a workflow automation platform orchestrating the workflow, AI language model technology via API for reading policies, and ExcelJS for building the final workbook. Fewer moving parts, easier to maintain, easier to extend.
